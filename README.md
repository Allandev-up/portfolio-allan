# Portfolio Allan

Site statique bilingue (français / anglais), sans dépendances de compilation.

## Aperçu local

Lancer `python -m http.server 8000` depuis ce dossier, puis ouvrir http://localhost:8000.

## Contenu

- `index.html` : contenu français accessible même sans JavaScript.
- `style.css` : présentation responsive et prise en compte du mouvement réduit.
- `app.js` : traductions et choix de langue, avec stockage facultatif.
- `CV_Allan_Wilfried.pdf` : CV téléchargeable.

Le dépôt public vérifié le 12 septembre 2026 est `Allandev-up/portfolio-allan`.
Piolo, Medicamerconnect, Jobsearch et Justice Facile sont des projets privés confirmés par Allan. Les cartes ne contiennent pas de liens de dépôt ni de technologies inventées : les technologies et les liens restent à fournir. Les descriptions fonctionnelles et la présence d’IA proviennent des précisions d’Allan ; le code privé n’a pas été audité.

Aucune mise en production automatique n’a été ajoutée.
